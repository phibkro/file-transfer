Privacy

This software is built to know as little as possible about you and your files. This page describes the software as published. Anyone may run their own instance, possibly modified, and its operator is responsible for it.

Never stored on a server

  • Your files, in any form, encrypted or not.
  • File names, types or counts.
  • The link, its secret, or any key.

What a server keeps, and for how long

What Why Kept until
A room: a hash of its room token, how many recipients it admits, and how many bytes it relayed To admit only browsers holding the link, and to apply the operator's relay limit A day after everyone leaves the room
A salted hash of your network address, with a count of rooms created To limit how many transfers one network starts per hour The end of that hour
Only if the operator turns counting on: counts per hour of rooms, recipients, completed and failed transfers, size buckets and megabytes relayed, with nothing that identifies anyone So the operator can see that the service works 90 days by default, set by the operator

The hosting provider may keep its own request logs under its own terms. Those logs can include network addresses and room identifiers, never the part of the link after #. On Cloudflare, this software turns off the Worker's own request logging.

Direct connections and your network address

When both sides allow it, the two browsers connect directly (WebRTC) and the encrypted pieces skip the server. To find a direct route, each browser asks a STUN server for its public network address (Cloudflare's by default; the operator chooses), and the two browsers pass their addresses to each other through the room, which forwards them and keeps nothing. So the other side learns your network (IP) address, which the server sees anyway. To keep it from them, turn off "Direct connections" at the bottom of the main page: everything then goes through the server's relay.

In your browser

  • Received files are kept in this site's private browser storage until you save them, remove them, or leave the page. The next visit deletes anything left behind.
  • "Storage in this browser", at the bottom of the main page, shows how much is stored and clears it.
  • Whether you allow direct connections is remembered in this browser only.
  • This software sets no cookies. A hosting provider's bot protection may set its own (Cloudflare's challenge page does).

No tracking

  • No analytics, no advertising, no third-party scripts or fonts.
  • Nothing is sent to the people who make this software. An instance never phones home.
  • Counting is off unless the operator turns it on. Any instance tells you whether it counts at /api/instance.
