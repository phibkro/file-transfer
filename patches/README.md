# Patches

Bun applies these to dependencies on install (`patchedDependencies` in the root `package.json`). Each one is a bug fix
waiting for upstream; drop it when the dependency is upgraded past the fix.

| Patch                                           | What it fixes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@alchemy.run%2Fcloudflare@2.0.0-beta.84.patch` | A Worker Preview's static asset settings. Alchemy sends a Preview deployment's `assets.config` in its own camelCase shape (`notFoundHandling`, `headers`) to an API field its client leaves untyped, so Cloudflare drops `_headers`, `_redirects`, `not_found_handling` and `run_worker_first` without an error. Previews then served the preview frame without its sandbox CSP and the app's scripts without CORS, and the end-to-end preview checks failed on every pull request. The patch converts the config to the API's field names. Ported from `alchemy@2.0.0-beta.83.patch` when the Cloudflare provider moved to its own package: in 2.0.0-beta.84 `Workers/WorkerProvider.ts` still passes `mergeAssetsConfigFiles(...)` through, and `@distilled.cloud/cloudflare` 1.0.0-rc.17 still types `CreatePreviewDeploymentMetadataAssets.config` as `unknown`. (The file name is how `bun patch` writes a scoped package.) |
| `alchemy@2.0.0-beta.84.patch` | Alchemy under Effect 4.1. Effect 4.1.0 replaced the `effect/Crypto` module with one service per family under `effect/crypto/` and dropped crypto from the platform services layers ([Effect-TS/effect@8f23668](https://github.com/Effect-TS/effect/commit/8f236683ad92bc4b4f58e16e91d40ce713c20578)). Alchemy 2.0.0-beta.84 still imports `effect/Crypto`, so `@alchemy.run/cloudflare` (and with it `alchemy.run.ts`, `alchemy deploy` and `alchemy destroy`) fails when it loads, while type checks with `skipLibCheck` still pass. The patch backports the `packages/alchemy` part of [alchemy-run/alchemy@9d0709d](https://github.com/alchemy-run/alchemy/commit/9d0709d22af080035dce48856b3c31cfc43bd938) (`fix: support effect 4.1`, on Alchemy's main but in no release yet): OAuth state and PKCE use `SecureRandom` and `Digest` (`src/Auth/OAuthFlow.ts`); `StackServices` names `Digest` and `SecureRandom` instead of `Crypto` (`src/Stack.ts`); and `src/Util/PlatformServices.ts` provides `SecureRandom.layerWebCrypto` and `Digest.layerWebCrypto` beside the Bun or Node services. `lib/` gets the same change compiled, since Alchemy resolves `src/` under the `bun` condition and `lib/` otherwise. No other installed module of `alchemy`, the `@alchemy.run` scope or the `@distilled.cloud` scope imports an Effect module or name that 4.1 removed. The same file is merged in heim, filmder and finnbydel, which share the Alchemy state store. Drop it at alchemy 2.0.0-beta.85. |
