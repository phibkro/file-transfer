# Patches

Bun applies these to dependencies on install (`patchedDependencies` in the root `package.json`). Each one is a bug fix
waiting for upstream; drop it when the dependency is upgraded past the fix.

| Patch                         | What it fixes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `alchemy@2.0.0-beta.83.patch` | A Worker Preview's static asset settings. Alchemy sends a Preview deployment's `assets.config` in its own camelCase shape (`notFoundHandling`, `headers`) to an API field its client leaves untyped, so Cloudflare drops `_headers`, `_redirects`, `not_found_handling` and `run_worker_first` without an error. Previews then served the preview frame without its sandbox CSP and the app's scripts without CORS, and the end-to-end preview checks failed on every pull request. The patch converts the config to the API's field names. Still present in 2.0.0-beta.84 (`@alchemy.run/cloudflare`). |
