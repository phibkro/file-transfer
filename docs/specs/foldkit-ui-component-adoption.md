# Foldkit UI component adoption

Scope: the complete current-main application and requested Local Library in `foldkit-ui-library-repair.md`, including operator/site, share, settings and sandbox preview surfaces. Source: Foldkit/UI 0.170.0, upstream revision a471adb24d750ab9e8d8312edad53ff6f26d961b.

## Method

The application scope was frozen before the current Jevify run. All 29 public exports were judged in one batch with mutually exclusive use-now, conditional, defer, not-applicable and mixed labels, plus a security/lifetime flag. Prior narrower-scope verdicts were invalidated. Current classifier counts: 23 use-now and 6 not-applicable, no failures. 107 source files were excluded as independent units because they were tests, internal helpers or re-exports, not additional public components. Evidence was capped at 18,000 characters per unit, with bounded source windows. Eleven large component windows and three helper windows were partial; truncation, relevance, uncertainty and security rules escalated all 29 units. The decisions below confirm or overturn the classifier using source/API evidence, rather than adopting every suggested widget.

## Decisions

| Component     | Decision                    | Application and source evidence                                                                                                                                                                                                             |
| ------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File Drop     | Use                         | Accessible chooser/drop Submodel for Quick Share and Library. OutMessages contain native Files, not durable handles; parent messages stay private and Library discloses captured-file/reselection limits.                                   |
| Button        | Use                         | Stateless actions/disabled semantics across transfer, catalog and operator controls.                                                                                                                                                        |
| Input         | Use                         | Single-line names, read-only link and private password/token fields.                                                                                                                                                                        |
| Checkbox      | Use                         | Controlled indexed-file selection.                                                                                                                                                                                                          |
| Switch        | Use                         | Explicit remembering and direct-connection preferences with descriptions.                                                                                                                                                                   |
| Fieldset      | Use                         | Labeled related controls, collection creation and operator/session forms.                                                                                                                                                                   |
| Select        | Use                         | Native collection choice; custom popup selection adds no needed behavior.                                                                                                                                                                   |
| Nav           | Use                         | Site/app destinations with current-page semantics, including generated static layout.                                                                                                                                                       |
| Progress      | Use                         | Preparation/transfer work progress and indeterminate operations, not a scalar meter.                                                                                                                                                        |
| Tabs          | Use                         | Device versus Cloud are alternative Library panels; parent owns selected location.                                                                                                                                                          |
| Dialog        | Use                         | Preview, version/reconnection review and destructive confirmations with focus/Escape ownership.                                                                                                                                             |
| Disclosure    | Use                         | Existing storage/direct settings, secret reveal and optional QR/report details are explicit disclosure interactions. The helper is controlled/stateless, not a fake Submodel.                                                               |
| Meter         | Use when the ratio is valid | Operator completion ratio is a bounded scalar measurement. Render only defined, valid ratio data; show unknown/unavailable states explicitly rather than silently clamping invalid statistics. Keep uPlot for the actual time-series chart. |
| Anchor        | Internal only               | Floating-positioning infrastructure for components that require it, not a site navigation or standalone product feature.                                                                                                                    |
| Animation     | Defer                       | Optional transitions add no required application behavior; use component-owned lifecycle support only where needed.                                                                                                                         |
| Calendar      | Not applicable              | No date-grid selection. Dates on charts and file metadata are display values.                                                                                                                                                               |
| Date Picker   | Not applicable              | No user-selected date or storage-expiry input in this delivery.                                                                                                                                                                             |
| Combobox      | Defer                       | Searchable custom choice is not needed where the native Select covers collection selection.                                                                                                                                                 |
| Listbox       | Defer                       | Duplicates native Select for the present choices and adds popup state.                                                                                                                                                                      |
| Drag and Drop | Not applicable              | Reorders/moves application entities; external file dropping is File Drop. Collection reordering was not requested.                                                                                                                          |
| Hover Intent  | Not applicable              | Delayed hover panels are not required; do not use hover to reveal keys or hide essential mobile guidance.                                                                                                                                   |
| Menu          | Defer                       | Existing visible file/action buttons preserve discoverability and keyboard access; no context-menu requirement.                                                                                                                             |
| Popover       | Defer                       | No required floating nonmodal panel; confirmations and previews use Dialog.                                                                                                                                                                 |
| Radio Group   | Defer                       | Binary preferences use Switch; storage location uses Tabs and collection choice uses Select.                                                                                                                                                |
| Slider        | Not applicable              | Operator settings are displayed, not a continuous numeric range editor.                                                                                                                                                                     |
| Textarea      | Not applicable              | No multiline editing requirement; reports are explicit read/copy output, names/credentials are Input fields.                                                                                                                                |
| Toast         | Defer                       | Persistent inline operation status/errors remain actionable; adding dismiss/swipe timers is not needed.                                                                                                                                     |
| Tooltip       | Defer                       | Visible labels and descriptions carry privacy, consent and file-state information. No essential information goes behind hover.                                                                                                              |
| Virtual List  | Defer                       | Requires measurement/scroll ownership and should follow measured catalog-size pressure, not speculative complexity.                                                                                                                         |

Final selection: 12 unconditional uses, one bounded-ratio use, one internal helper, nine deferred components and six unrelated components. Stateful components use h.submodel/Update.foldChild. Stateless helpers receive the owning HtmlBuilder directly. Existing uPlot remains a genuine foreign widget under an element-owned Mount with teardown; Foldkit UI has no time-series chart export to substitute for it.
